Flow cytometry · FCS gate explorer

Inspect list-mode events, select detector channels and export a rectangular gate.

Local processing · No upload

1. Load data

Supports single-dataset list-mode FCS with float, double or 8/16/32-bit integer events, up to 250,000 events and 128 MiB. No compensation or transformation is applied by this app.

2. Choose axes

3. Set rectangular gate

Drag across the scatter plot or enter channel values below. Bounds are inclusive.

Exploratory analysis only. No compensation, spectral unmixing, logicle transformation, automated population identification, or clinical classification is performed.
